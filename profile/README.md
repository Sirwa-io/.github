## Free engineering tool

### [UDS NRC Decoder →](https://sirwa.io/tools/uds-nrc-decoder)

Look up a UDS negative response code and get its meaning, category, and practical checks for your next diagnostic step.

- **Free to use in your browser** — no account or installation needed.
- **Simple input** — enter one hexadecimal byte, such as `22`, `0x22`, or `0X78`.
- **Local, deterministic lookup** — decoding uses a curated dataset in the browser.
- **Clear scope** — common NRCs are covered; unsupported values are identified without a guessed meaning.

For example, `0x22` returns **Conditions Not Correct**, with checks for ECU state, the active diagnostic session, and service prerequisites.

The decoder covers a subset of common NRCs. Use the applicable ISO 14229 edition and your OEM diagnostic documentation for project-specific interpretation.
